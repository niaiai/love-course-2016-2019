# 乌鸦救赎《终极火箭班》：乌鸦经典语录：核心自信(1)

其实核心自信练到最后的一个效果，就是不能够做到，不然失望无能够不影响的情绪，能够保持一个自在，这个自在是我觉得是比自信更好的，因为自信的话你会改革自信潮红，就跟听了摇滚音乐的感觉，有点上头。

它的自在的话是怎么样，就是微信当中没有任何太大情绪波动，但是你去感觉到自己也很舒服，如果喜欢的是那种感觉，就不管你要对任何场景说，你都能够，都能够让自己表现出非常地自在，舒适像是在自己的后院一样，对吧。

你能够做到在自己的后院，透了内裤各种，马列脑很开心，很舒适很舒适之外，我说的就是要让自己这种状态，能够在任何时间任何地点都可以展现出了。
