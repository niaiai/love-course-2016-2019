# 乌鸦救赎《终极火箭班》：乌鸦经典语录 第二期：语言侵略话术

我聊到跟女孩聊到说，男女妇科的问题，她不是有点妇科毛病，我说，我去用语言情侣吧，但是我们还不是那样的关系，我说，我说那个，你那个有妇科病，赶快去看一下吧，如果说以后生不了孩子，可不要你。

然后她结果回了个茶，不要你别养，然后我说，不要养了，她说，不要你别养，不要有人养，我说，不要你，不是我，不要你，是你老公不要，你想啥的，就是你看，我给大家，在那里带个语言情侣，这就是语言情侣的一个算例。

当时我们不是恋爱关系，但是我直接用下一关，接著她会出现的话，与根据的照片，然后她拒绝我，然后我会有意义，就是一旦被对方拒绝之后，你用两种办法，一种是开玩笑，通用话题是开玩笑，你吃在原不回去了。

那就说开玩笑，但是如果说能语，或其实刚才我说那哪里，不要你是，不是我不要你，你老公不要你，这是属于就是，你话题可以语言，或觉得那么，你就可以用这种，能语言或是话题去说，如果是在原不回去了。

随便我给你看一个玩笑而已，这是通用，但是说这个通用的话题是说，叫我不认太好，那听明白这个可以，把这个语言情侣也就是，赶了咱们刚才讲那个案是，提前把下一个结段，才会出现的一些场景，提前说出来。
