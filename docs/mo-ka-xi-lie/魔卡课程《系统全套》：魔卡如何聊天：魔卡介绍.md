# 魔卡课程《系统全套》：魔卡如何聊天：魔卡介绍

【词曲】，大家好，我是魔卡，我的极冠是东北吉林，我1983年出生在福建全州，小时候在江西南昌长大，中学去了广东深圳，大学决断一直在海外漂泊，回国后又一直在北京工作，我是一个单亲家庭的孩子。

我的父母在我六岁的时候离异，我从小就比较独立，习惯自己的事情自己做主，从父母离婚时，我选择跟谁这个问题开始，一直到现在，在我记忆里，我人生当中所有的重大决定，都遵循了我自己的意志，我有过一段长达十年。

1999年的初恋，从1997年开始，一直到2008年结束，我是我们那个年级的第一队，也是我们那个年级最晚分手的一队，更奇葩的就是在高三，就是高考总动员的时候，用我们高中的教导主任的话来说。

就是不好好学习，准备考试，居然谈起了跨越两个半球的恋爱，就是说我和我的前女友，因为她高二的时候去了澳洲，而我在高三毕业之后去了欧洲，这十年间我遭遇了失恋晚回，再失恋再晚回，再失恋再晚回不了的经历。

我还有过一段长达十年的游学经历，从2001年出国到2012年回国，中间在法国、韩国、美国、日本，这几个国家都分别的长达国，一年以上的时间，虽然我会因与法语、日语、韩语，但是我并没有取得大学毕业文品。

当初也正是因为在法国没有取得文品，觉得很没面子，不敢回来面对这个现实，所以才一个国家、一个国家的去走、去有利，我试图找到一个解决办法，但是最终也没有解决文品这件事情，不得以在我30岁的时候回国了。

也许有很多同学会觉得，Mokka是富尔代去了这么多的国家，其实Mokka是一路情工检学过来的，即便这样我还是向朋友借了钱，这些钱大概是30万左右，所以在我30岁回国的时候。

我是一个没有学历、没有爱情、没有工作，只有30万债务的一个彻底的失败者，所以那个时候我的情绪，非常的益语、状态非常的不好，我益语到调头发、自卑、非常富能量、富能量爆仿佛，然后我被钱率有抛弃了。

所以我觉得我没有女人喜欢，没有女人会喜欢我，还觉得自己没有文品，所以所有人都看不起我，在这样的一个背景下，我来到刚刚成立的坏男孩学院，带著感情失败的10万个为什么。

我每天查阅吸引力源、理资料、开展这种提升吸引的资深建设，进行练习吸引的实际上活动，半年后，突飞门、盟禁、拖胎、换骨，2013年我已经完全解决了自己在情感上的问题和困扰，并且掌握了吸引力的原理。

开始设计和交受、换了还学院线上的VIP网络课程，以及线下的实战课、魅力工程和李江济化，2013年全年Mokai TV的158个女生，成为了行业里速度最快，数量最多、智量最高的纪录保持者。

那时候圈里对Mokai有很多的称呼、称卫，比如说夜店小王子、白富美推土鸡，然后村村都有帐门娘、夜夜都能当新郎，除了新疆、西藏、内蒙古和港澳台，全国其他省份都有Mokai的妹子。

12生肖、12新作全部都收集齐全了，那是一段现在想来那是一段非常疯狂、非常荒唐的精力，Mokai也因此付出了代价，现在Mokai已经订婚了，也不想在无修指的TD妹子。

其实很多时候短期关系的感觉并没有我们想像的那么好，现在Mokai的愿望就是在总结自身经验的教训的基础上，不断的带给大家正确的约会和吸引的知识。

我现在专注于挽回练习、帮我的客户挽回练习和长期关系的技巧和方法，最后给那些正在经历这个情感不顺与生活逆境的同学们，从1998年到2013年Mokai都是一路非常坎坷。

幸福指数非常低的可以说是混过来或者熬过来的，整整十多年的时间，那个时候我觉得全世界最惨的人就是我了，可是现在看来那是我人生当中非常宝贵的一笔财富，如果没有那些年的苦难不会有现在的魔卡。

现在我总是喜欢很澳交的对别人说，我的青春非常的精彩，有过一段轰轰烈烈的爱情，一爱就爱了十年的时间，有过一场说走就走的旅行，一走就绕地球一圈，现在又做著这么起趴新潮的一份工作，所以积极起来面对生活。
